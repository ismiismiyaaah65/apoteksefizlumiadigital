# Sefizlumia Apotek — Prototype
Prototype website statis berdasarkan spesifikasi Sefizlumia Apotek.

Fitur demo:
- Homepage responsive
- Konsultasi apoteker dengan alur 4 tahap
- Chat konsultasi demo
- Katalog dan pencarian produk
- Keranjang dan checkout demo
- Upload resep
- Login/Register demo
- Layanan, artikel, lokasi dan footer
- Mobile bottom navigation

Cara menjalankan:
1. Buka `index.html` di browser.
2. Semua interaksi demo berjalan tanpa backend.

Catatan:
Data apoteker, produk, harga, kontak, lokasi, dan akun pada prototype adalah data contoh.
Untuk versi produksi diperlukan backend, database, autentikasi, payment gateway, sistem antrean real-time, penyimpanan dokumen, serta integrasi chat/video yang aman.
